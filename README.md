# 🧠 Quiz – Interactive Quiz Application

An interactive web-based Quiz Application built to provide an engaging and user-friendly quiz experience. Developed using modern front-end technologies, this project combines a responsive interface with database integration.

## ✨ Features

- Interactive quiz application
- Modern and responsive user interface
- Component-based architecture using React
- Type-safe development with TypeScript
- Utility-first styling with Tailwind CSS
- Supabase integration for backend functionality
- Clean and organized project structure

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| TypeScript | Type-safe programming |
| Vite | Development server and build tool |
| Tailwind CSS | UI styling |
| Supabase | Backend and database integration |
| Lucide React | Icons |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/shouryajain-2908/quiz.git
```

### 2. Navigate to the Project

```bash
cd quiz
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Supabase

Set up your Supabase project and configure the required connection credentials according to the application's source code.

Keep private credentials out of your GitHub repository.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
